# Secure-Authentication-system-C-File-Based-User-Management
A C++ based secure authentication system featuring file-based user management, user registration, login authentication, password hashing, and role-based access control.
Secure Authentication System: C++ File-Based User Management

Project Overview

This microproject implements a secure authentication system using C++. It provides file-based user management and authentication functionality.

Features

- User Registration
- User Login and Authentication
- Password Hashing
- File-Based Data Storage
- Role-Based Access Control
- User Account Status Management
- Persistent User Records

Technologies Used

- Programming Language: C++
- Storage: File Handling
- Compiler: GCC / MinGW / Any Standard C++ Compiler
- IDE: Visual Studio Code / Code::Blocks

Project Structure

├── src/
├── include/
├── docs/
├── screenshots/

How to Run

1. Clone this repository.
2. Open the project in your C++ IDE.
3. Compile the source files.
4. Run the generated executable.

Compilation

g++ src/*.cpp -o authentication

Project Purpose

This project was developed as an academic microproject to demonstrate C++ programming, file handling, authentication, and user management concepts.
